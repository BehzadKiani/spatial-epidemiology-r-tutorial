# Spatial Epidemiology in R

Teaching materials for Session 2: Spatial Epidemiology in R.

## Topics

This tutorial introduces:

- Spatial data handling in R
- Disease mapping
- Spatial neighbourhood structures
- Global Moran's I
- Local Moran's I (LISA)
- Multiple-testing correction
- Sensitivity analysis using alternative spatial weights
- Kulldorff spatial scan statistics

## Files

- `index.qmd` – Complete Quarto tutorial
- `QLD_SA2_Spatial_Epidemiology_Course.gpkg` – Queensland SA2 teaching dataset
- `index.html` – Rendered tutorial

## Software

The tutorial uses R and the following main packages:

- sf
- ggplot2
- spdep
- SpatialEpi
